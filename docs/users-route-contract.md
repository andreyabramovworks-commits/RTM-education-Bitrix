# Контракт раздела «Пользователи и роли»

До переноса экран собирался в legacy DOM из пользователей Bitrix24, отделов и ролей приложения. Он показывал активных сотрудников, поиск по имени/email, фильтры по отделу и роли, сортировку по имени или роли, синхронизацию и изменение роли. Изменять роли могли только администратор и разработчик; основной разработчик и администраторы Bitrix24 защищены отдельными серверными правилами.

Теперь экраном владеет `UsersAdmin.jsx`. Он читает `GET /api/v47/users` и `GET /api/v47/departments`, а изменение роли выполняет только через `PUT /api/v47/users/{id}/role`. Сервер отдаёт право редактирования для каждой строки и сам проверяет изменение. После сохранения React обновляет общий снимок данных, который нужен остальным действующим сценариям. Старый `#adminUsers`, его три версии отрисовки и два варианта диалога удалены.

Локальные проверки покрывают выдачу прав, фильтры и первоначальное отображение экрана. Синхронизацию и изменение роли в авторизованном Bitrix24 следует проверить до выпуска.

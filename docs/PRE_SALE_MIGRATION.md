# Перед подготовкой RTM Education к продаже

Этот список фиксирует корпоративные допущения, которые намеренно сохранены в текущей версии.

- Заменить `PRIMARY_DEVELOPER_BITRIX_ID = "36"` в `backend/app/company_policy.py` на tenant-aware настройку и перенести защиту роли в конфигурацию организации.
- Удалить миграционную привязку пользователя `36` после появления tenant-aware владельца.
- Перенести корпоративные адреса, Bitrix application ID и правила ролей в настройки организации.
- Выполнить миграцию существующих Excalidraw-сцен через реестр `RTMSceneMigrations`, не удаляя неизвестные поля сцены.
- Перед включением нескольких организаций добавить изоляцию данных по tenant ID во все таблицы, API и фоновые задачи.

Секреты, токены и значения `.env` в этот документ не добавляются.

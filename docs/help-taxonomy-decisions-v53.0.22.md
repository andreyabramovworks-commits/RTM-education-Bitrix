# Решения по подсказкам v53.0.22

Источник: пользовательская карта `navigation-and-tooltip-taxonomy.md`. Тексты сопоставлены с существующим каталогом `RTMHelp`; файл-источник не изменялся и не включался в коммит.

| Спорный момент | Принятое решение | Итоговый текст/поведение |
| --- | --- | --- |
| Где показывать `?` | Только рядом с крупными заголовками и ключевыми понятиями | На обычных кнопках и полях используется подсказка при наведении с задержкой 260 мс |
| Состояние при первом входе | Подсказки выключены | Маркеры, hover-карточки и клики неактивны до включения режима |
| Синхронизация устройств | Серверная пользовательская настройка | Ключ `__mode__` в существующем API предпочтений; локальное значение используется только как быстрый кэш |
| Старые тексты и новая карта | Сохранить более точные прикладные формулировки действующего интерфейса | Термины «редакция», «кампания», «ответственные», «срок» и «центр проверок» оставлены из действующего каталога; навигационные формулировки взяты из карты |
| Вложенные понятия | Сохранить действующую наследуемую цепочку | Ссылка внутри расширенной карточки открывает следующий уровень, не закрывая родительский |
| Сенсорные устройства | Не полагаться на hover | Карточка открывается кнопкой `?`, закрывается крестиком или Escape; состояние одинаково на всех устройствах |
| Системная тёмная тема | Не менять учебный интерфейс | Приложение объявляет `color-scheme: only light`; цвет бренда всегда приходит из общей серверной настройки администратора |

Покрытые группы: пользовательская навигация и обучение; База знаний; профиль; синхронизация; роли; редакции и способы ознакомления; получатели, подразделения и ответственные; сроки и новые сотрудники; активные кампании; Центр проверок; возврат и история.

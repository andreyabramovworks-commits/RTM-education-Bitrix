# Контракт дашборда

До переноса дашборд строился из legacy материалов, назначений, прогресса, событий и пользователей. Он показывал число материалов и пользователей, завершённые и находящиеся в работе назначения, распределение статусов, пять последних событий и пять последних материалов. Из карточек можно было перейти к списку пользователей, общему журналу, списку материалов или открыть конкретный материал.

Теперь экраном владеет `DashboardAdmin.jsx`, а данные собирает `GET /api/v47/dashboard` для преподавателя и старших ролей. Переход к конкретному материалу остаётся через действующий редактор материалов: React переключает маршрут и передаёт ID через существующий мост. Старые `#adminDashboard`, обработчики карточек и функция `renderDashboard` удалены; изменения legacy данных лишь сообщают React, что сводку нужно обновить.

Локально проверены вычисление показателей, ID переходов, состояние загрузки, тесты и сборка. Переходы к материалам в авторизованном Bitrix24 ещё требуют проверки.
